A one-sentence pitch for a lazy AI agent: an absurd micro-startup selling $4 apology letters to guilty suburban dog owners whose dogs ate their neighbors' prized garden gnomes — the AI writes, charges, and delivers while napping, no human ever involved.

## Run it

```bash
python3 main.py
```

This prints the pitch and writes it to `/output/entry.txt`.
